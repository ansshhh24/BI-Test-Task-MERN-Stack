# missing you ♡

A tiny, very cute single-page love note built around one feeling: *missing you*.

## What's inside
- **Flippable photo stickers** — tap either photo to flip it and reveal a little note on the back.
- **The Miss-o-meter** — press and hold the `hold me 🫶` button and watch how much someone is missed… it overflows to ∞.
- **Heart bursts everywhere** — tap anywhere and hearts float up.
- **A "thinking about you" ticker** — a playful live clock.

## How to open
It's a self-contained static page — no build step.

```bash
# from this folder
open index.html        # macOS
# or just double-click index.html
# or serve it:
python3 -m http.server 8000   # then visit http://localhost:8000
```

Files: `index.html`, `photo1.jpg`, `photo2.jpg`.
